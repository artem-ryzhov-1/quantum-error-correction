# Quantum error correction (QEC) demonstration project

I created 5 Jupyter notebooks with short theory and implementation of the most important QEC codes: 3-qubit bit-flip code, 3-qubit phase-flip code, Shor's 9-qubit code, Steane [7,1,3] code, surface code. They implement these QEC codes using qiskit lib. They can be run in Google Colab. The clean notebooks are in the notebooks_clean directory, and notebooks after running in Google Colab (with results, diagrams and graphs) are in the notebooks_executed directory.
